`definable.browser` exposes browser automation as a toolkit. In production, that usually means `PlaywrightBrowser` plus `BrowserToolkit`. In tests or local harnesses, you can inject any `BaseBrowser` implementation and keep the examples deterministic.

## What browser automation is for

Use the browser layer when the agent needs a real page session instead of a plain HTTP call:

- navigating authenticated or JavaScript-heavy sites
- reading structured page state before acting
- clicking, typing, uploading, and extracting data
- attaching browser capabilities to the same agent that already uses tools, knowledge, and memory

If a normal API call is enough, prefer a regular tool. Browser automation is heavier and should be reserved for tasks that truly require page state.

## Public API

| Type | Purpose |
| --- | --- |
| `BrowserToolkit` | Expose browser capabilities as agent tools |
| `PlaywrightBrowser` | Playwright-backed browser implementation |
| `BrowserConfig` | Browser launch and connection settings |
| `BaseBrowser` | Browser interface for custom implementations |

## Real browser vs injected browser

- Use `PlaywrightBrowser` when you want a real Chrome-compatible browser.
- Use a custom `BaseBrowser` when you need deterministic testing or a different browser backend.

The tested snippet below uses an injected mock browser so the example remains stable in CI. In production you would swap that browser for `PlaywrightBrowser(config=BrowserConfig(...))`.

## Tested example

```python
import asyncio

from definable.browser import BrowserToolkit

from examples.docs.support import MockBrowser


async def main() -> None:
    async with BrowserToolkit(browser=MockBrowser()) as toolkit:
        navigate = next(tool for tool in toolkit.tools if tool.name == "browser_navigate")
        snapshot = next(tool for tool in toolkit.tools if tool.name == "browser_snapshot")

        result = await navigate.entrypoint(url="https://example.com")
        tree = await snapshot.entrypoint()

        assert result == "Navigated to https://example.com"
        assert "ref=e1" in tree


asyncio.run(main())
```

## Production notes

- Install the browser extra before using Playwright-backed automation.
- Make Chrome, Chromium, Brave, or Edge available on the machine where the toolkit runs.
- Prefer `BrowserConfig(cdp_url=...)` when you want to attach to an existing browser session.
