```python
from pathlib import Path


scripts = sorted(Path("examples/docs").glob("*.py"))

assert len(scripts) >= 10
assert all(script.suffix == ".py" for script in scripts)
```

The docs use a curated example tier under `examples/docs/`. These scripts are intentionally smaller and more deterministic than the broader example tree, and they serve the same role as a professional cookbook: copyable patterns with a validation guarantee.

## How to use this section

- start with the overview page for the capability you are exploring
- copy from the curated scripts when you want a minimal pattern
- move to the broader example tree only when you need provider-specific or service-backed setups

## Example tiers

| Tier | Location | Purpose |
| --- | --- | --- |
| Verified docs examples | `examples/docs/` | Stable, offline-friendly examples referenced by the rewritten docs |
| Broader topic examples | `examples/agents/`, `examples/browser/`, `examples/mcp/`, and other topic folders | Larger or provider-specific examples that may require external services |

## What is validated

- Every Python snippet on the rewritten module pages.
- Every curated example script listed on the examples pages.
