```python
from pathlib import Path


scripts = [
    "examples/docs/browser_toolkit.py",
    "examples/docs/knowledge_basics.py",
    "examples/docs/mcp_basics.py",
    "examples/docs/memory_basics.py",
    "examples/docs/models_basics.py",
    "examples/docs/skills_basics.py",
    "examples/docs/tools_basics.py",
    "examples/docs/toolkits_basics.py",
]

assert all(Path(script).exists() for script in scripts)
```

These scripts cover the browser-side capabilities the agent layer typically composes with. They are deterministic and run locally without live provider calls.

| Script | Covers |
| --- | --- |
| `python examples/docs/browser_toolkit.py` | `BrowserToolkit` with an injected `BaseBrowser` implementation |
| `python examples/docs/knowledge_basics.py` | `Knowledge` with a mock vector store |
| `python examples/docs/mcp_basics.py` | `MCPClient` and `MCPToolkit` with a local mock MCP server |
| `python examples/docs/memory_basics.py` | `Memory` with `InMemoryStore` |
| `python examples/docs/models_basics.py` | Provider classes and model-string resolution |
| `python examples/docs/skills_basics.py` | Inline `Skill` composition |
| `python examples/docs/tools_basics.py` | `@tool` and `Function` metadata |
| `python examples/docs/toolkits_basics.py` | Custom `Toolkit` composition |
