## Tested registry surface

```python
from definable.skill import SkillRegistry


registry = SkillRegistry()
on_demand = registry.as_on_demand()

assert on_demand.name == "skill_library"
assert "activate_skill" in [tool.name for tool in on_demand.tools]
assert bool(registry.to_prompt()) is True
```

See [`Skill Registry`](/skills/registry) for the full module documentation.
