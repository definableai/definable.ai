Migration work is safest when you keep one idea fixed at a time: current version, target version, deployment shape, and validation plan.

## Migration rule

1. Record the currently deployed version.
2. Pin the target version deliberately.
3. Validate the smallest local run.
4. Validate the runtime and interface surface.
5. Validate production-only concerns last.

## Tested example

```python
from packaging.version import Version

current = Version("0.8.0")
target = Version("0.8.1")

assert target >= current
assert target.release[:2] == (0, 8)
```
