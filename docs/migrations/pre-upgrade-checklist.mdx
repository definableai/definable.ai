The biggest upgrade mistake is changing version and deployment shape at the same time. Record the current state first.

## Checklist

- record the currently deployed package version,
- record the enabled interfaces and runtime routes,
- keep one mock-backed local configuration ready,
- note which extras the environment currently installs,
- identify the smallest smoke test that proves the service is alive.

## Tested example

```python
import tomllib
from pathlib import Path

pyproject = tomllib.loads(Path("pyproject.toml").read_text())
version = pyproject["project"]["version"]
extras = pyproject["project"]["optional-dependencies"]

assert isinstance(version, str)
assert "runtime" in extras
assert "discord" in extras
```

## Why this matters

If an upgrade fails, you need a precise baseline. “It used to work” is not enough. You need the previous version, enabled extras, and deployment surface.
