---
title: Claude Code Agent
description: Wrap the Claude Code CLI in the same execution model as the rest of the Definable stack.
---

`ClaudeCodeAgent` is the bridge between the Claude Code CLI and the Definable runtime. It lets you keep Claude Code’s coding workflow while still layering Definable features such as memory, knowledge, tools, guardrails, and tracing around it.

## Tested example

```python
from definable.claude_code import ClaudeCodeAgent

agent = ClaudeCodeAgent(
    model="claude-sonnet-4-6",
    instructions="Senior backend engineer.",
    allowed_tools=["Read", "Write", "Edit"],
    cwd=".",
)

assert type(agent).__name__ == "ClaudeCodeAgent"
assert agent.instructions == "Senior backend engineer."
```

## Operational notes

- Install and authenticate the Claude Code CLI before you run live executions.
- Treat `allowed_tools` and permission settings as part of your security boundary.
- Use the same guardrail and runtime concepts you use with ordinary agents.
