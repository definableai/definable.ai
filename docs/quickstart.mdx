This quickstart stays local and deterministic. Each section introduces one capability with a small tested snippet, so you can learn the API shape before you swap in live providers or external services.

## What you will learn

- how a single `Agent` run works
- how tools attach to that run loop
- how memory fits beside the agent
- how streaming exposes lifecycle events
- which pages to read next for production setups

## 1. Run an agent

```python
from definable.agent import Agent
from definable.agent.run import RunStatus
from definable.agent.testing import MockModel

agent = Agent(
    model=MockModel(responses=["Paris"]),
    instructions="Answer with the city only.",
)

output = agent.run("What is the capital of France?")

assert output.content == "Paris"
assert output.status == RunStatus.completed
```

## 2. Add a tool

```python
from definable.agent import Agent
from definable.agent.testing import MockModel
from definable.tool import tool


@tool
def get_weather(city: str) -> str:
    """Return a weather summary for a city."""
    return f"{city}: sunny"


agent = Agent(
    model=MockModel(responses=["Tokyo: sunny"]),
    tools=[get_weather],
    instructions="Use tools when they are relevant.",
)

output = agent.run("What is the weather in Tokyo?")

assert output.content == "Tokyo: sunny"
assert "get_weather" in agent.tool_names
```

## 3. Add memory

```python
import asyncio

from definable.memory import InMemoryStore, Memory
from definable.model.message import Message


async def main() -> None:
    async with Memory(store=InMemoryStore()) as memory:
        await memory.add(Message(role="user", content="My name is Ada."), session_id="demo")
        entries = await memory.get_entries("demo")

        assert entries[0].content == "My name is Ada."


asyncio.run(main())
```

## 4. Stream events

```python
from definable.agent import Agent
from definable.agent.testing import MockModel

agent = Agent(model=MockModel(responses=["hello world"]), instructions="Be brief.")
events = [event.event for event in agent.run_stream("Say hello") if hasattr(event, "event")]

assert "RunStarted" in events
assert "RunCompleted" in events
```
