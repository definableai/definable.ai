Middleware wraps `Agent.run()` and `Agent.arun()` with cross-cutting logic. The current implementation applies middleware only to the non-streaming run path.

## Tested custom middleware

```python
from definable.agent import Agent, MetricsMiddleware, MockModel


class CaptureMiddleware:
    def __init__(self) -> None:
        self.session_ids: list[str | None] = []

    async def __call__(self, context, next_handler):
        self.session_ids.append(context.session_id)
        result = await next_handler(context)
        result.metadata = {"captured": True}
        return result


capture = CaptureMiddleware()
metrics = MetricsMiddleware()

agent = (
    Agent(model=MockModel(responses=["hello"]), session_id="docs-session")
    .use(capture)
    .use(metrics)
)

output = agent.run("Hi")

assert output.content == "hello"
assert output.metadata == {"captured": True}
assert capture.session_ids == ["docs-session"]
assert metrics.run_count == 1
assert metrics.error_count == 0
```

## Retry behavior and registration order

`Agent.use()` keeps middleware in registration order, and the first middleware you add becomes the outermost wrapper.

```python
from definable.agent import Agent, MockModel, RetryMiddleware


attempts = {"count": 0}


class FlakyMiddleware:
    async def __call__(self, context, next_handler):
        attempts["count"] += 1
        if attempts["count"] == 1:
            raise ConnectionError("temporary")
        return await next_handler(context)


agent = (
    Agent(model=MockModel(responses=["recovered"]))
    .use(RetryMiddleware(max_retries=1, backoff_base=0.0, backoff_max=0.0))
    .use(FlakyMiddleware())
)

output = agent.run("retry")

assert output.content == "recovered"
assert attempts["count"] == 2
```

## Built-ins

- `LoggingMiddleware(logger, level=...)` logs run start, completion, and failures.
- `RetryMiddleware(...)` retries `ConnectionError`, `TimeoutError`, and `OSError`.
- `MetricsMiddleware()` tracks run count, error count, and average latency.
- `KnowledgeMiddleware(knowledge)` performs retrieval and injects formatted knowledge context before the main run.

## Notes

- Add retry middleware before middleware you want it to wrap.
- Middleware added with `use()` does not currently wrap `run_stream()` or `arun_stream()`.
- The `StreamingMiddleware` protocol exists for streaming-specific integrations, but it is not wired through `Agent.use()` today.
