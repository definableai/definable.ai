The deep research layer runs before the main answer when enabled. It is designed for questions that benefit from multi-source retrieval and synthesis rather than a single search hit.

## Tested configuration presets

```python
import asyncio

from definable.agent import DeepResearchConfig, MockModel
from definable.agent.research import DeepResearch


class FakeSearchProvider:
    async def search(self, query: str, max_results: int = 10):
        return []


async def main() -> None:
    config = DeepResearchConfig(depth="deep").with_depth_preset()

    assert (config.max_sources, config.max_waves, config.parallel_searches) == (30, 5, 8)

    researcher = DeepResearch(
        model=MockModel(
            responses=['{"needs_research": true, "reason": "Current information is required."}']
        ),
        search_provider=FakeSearchProvider(),
    )

    assert await researcher.needs_research("What changed this week?") is True


asyncio.run(main())
```

## Tested standalone engine flow

This example patches the internal research stages so the orchestration can be tested without network access.

```python
import asyncio
from unittest.mock import patch

from definable.agent import DeepResearchConfig, MockModel
from definable.agent.research import DeepResearch
from definable.agent.research.models import CKU, Fact, PageContent, TopicGap
from definable.agent.research.search.base import SearchResult


class FakeSearchProvider:
    async def search(self, query: str, max_results: int = 10):
        return [SearchResult(title="Example Source", url="https://example.com", snippet="Example snippet")]


async def fake_decompose(query, model):
    return ["What is the current architecture?"]


async def fake_read_pages(urls, **kwargs):
    return [PageContent(url=urls[0], title="Example Source", content="Important source content.")]


async def fake_compress_batch(pages, sub_question, original_query, model, **kwargs):
    return [
        CKU(
            source_url=pages[0].url,
            source_title=pages[0].title,
            query_context=sub_question,
            facts=[
                Fact(
                    content="The system uses deterministic documentation tests.",
                    entities=["system"],
                )
            ],
            relevance_score=0.9,
        )
    ]


async def fake_analyze(query, sub_questions, knowledge_graph, model):
    return ([TopicGap(topic=sub_questions[0], status="sufficient", confidence=0.9)], [])


async def fake_synthesize(query, knowledge_graph, sub_questions, config, model):
    return "Research context: deterministic documentation tests."


async def main() -> None:
    researcher = DeepResearch(
        model=MockModel(responses=["unused"]),
        search_provider=FakeSearchProvider(),
        config=DeepResearchConfig(depth="quick"),
    )

    with patch("definable.agent.research.planner.decompose", fake_decompose), \
         patch("definable.agent.research.reader.read_pages", fake_read_pages), \
         patch("definable.agent.research.compressor.compress_batch", fake_compress_batch), \
         patch("definable.agent.research.gap_analyzer.analyze", fake_analyze), \
         patch("definable.agent.research.synthesizer.synthesize", fake_synthesize):
        result = await researcher.arun("How does the docs pipeline work?")

    assert result.context == "Research context: deterministic documentation tests."
    assert result.metrics.total_sources_read == 1
    assert result.metrics.total_facts_extracted == 1
    assert result.sub_questions == ["What is the current architecture?"]


asyncio.run(main())
```

## What the layer adds

- query decomposition into focused sub-questions
- iterative search and reading
- fact extraction into CKUs
- gap analysis between waves
- synthesis into a context block for the final answer

## Notes

- `DeepResearchConfig(trigger="auto")` asks the model whether research is needed before starting the pipeline.
- Passing `deep_research=True` on an agent creates the layer with default config.
- You can also pass a prebuilt `DeepResearch` instance to `Agent(deep_research=...)`.
