Build agents incrementally. Start with a model and instructions. Add tools, memory, or knowledge only when the use case actually needs them.

## Smallest useful agent

```python
from definable.agent import Agent
from definable.agent.testing import MockModel

agent = Agent(
    model=MockModel(responses=["approved"]),
    instructions="Answer with a short decision.",
)

output = agent.run("Should I proceed?")

assert output.content == "approved"
```

## Add a tool

```python
from definable.agent import Agent
from definable.agent.testing import MockModel
from definable.tool import tool


@tool
def lookup_ticket(ticket_id: str) -> str:
    """Return the status of a support ticket."""
    return f"{ticket_id}: open"


agent = Agent(
    model=MockModel(responses=["T-42: open"]),
    tools=[lookup_ticket],
    instructions="Use the ticket tool when the user asks about ticket status.",
)

output = agent.run("What is the status of ticket T-42?")

assert output.content == "T-42: open"
```

## Add shared capability blocks

- Add [`Knowledge`](/knowledge/overview) when the answer should come from documents.
- Add [`Memory`](/memory/overview) when the answer depends on prior conversations.
- Add [`Guardrails`](/guardrails/overview) when policy or safety checks must wrap the run.
- Add [`Toolkits`](/toolkits/overview) or [`Skills`](/skills/overview) when capabilities should be grouped.

## Development guidance

- Keep the initial instructions short and specific.
- Add one capability at a time so behavior changes are easy to explain.
- Move repeated tool groups into a toolkit before the constructor becomes hard to scan.
