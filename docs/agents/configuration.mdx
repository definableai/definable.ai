`AgentConfig` holds the advanced execution settings for an agent. Capability layers such as memory, knowledge, compression, and reasoning are attached directly to `Agent(...)`, while loop behavior and defaults live in the config object.

## Basic configuration

```python
from definable.agent import Agent, AgentConfig
from definable.agent.testing import MockModel

config = AgentConfig(
    agent_name="Support Agent",
    max_iterations=15,
    max_retries=3,
)

agent = Agent(
    model=MockModel(responses=["done"]),
    instructions="Reply briefly.",
    config=config,
)

assert agent.config.agent_name == "Support Agent"
assert agent.config.max_iterations == 15
```

## Immutable updates

```python
from definable.agent import AgentConfig

base = AgentConfig(agent_name="Base Agent", max_iterations=10, max_retries=3)
custom = base.with_updates(agent_name="Custom Agent", max_iterations=20)

assert base.agent_name == "Base Agent"
assert custom.agent_name == "Custom Agent"
assert custom.max_iterations == 20
```

## What belongs in `AgentConfig`

| Area | Examples |
| --- | --- |
| Identity | `agent_id`, `agent_name` |
| Loop limits | `max_iterations`, `max_tokens`, `stream_timeout_seconds` |
| Reliability | `retry_transient_errors`, `max_retries`, `validate_tool_args` |
| Defaults | `session_state`, `dependencies`, `readers` |

## Example: combine config with capabilities

```python
from definable.agent import Agent, AgentConfig
from definable.agent.compression import Compression
from definable.agent.testing import MockModel
from definable.memory import InMemoryStore, Memory

config = AgentConfig(agent_name="Ops Agent", max_iterations=8)
compression = Compression(tool_results_limit=2)
memory = Memory(store=InMemoryStore())
agent = Agent(
    model=MockModel(responses=["done"]),
    config=config,
    memory=memory,
    compression=compression,
)

assert agent.config.agent_name == "Ops Agent"
assert compression.tool_results_limit == 2
assert memory is not None
```
