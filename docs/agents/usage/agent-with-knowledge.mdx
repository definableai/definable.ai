---
title: Agent with Knowledge
description: "Attach a knowledge base and validate retrieval with a deterministic vector store."
---

This example uses the same small in-memory vector store that powers the docs tests. The agent run is deterministic, and the retrieval context is validated separately.

```python
from definable.agent import Agent, MockModel
from definable.knowledge import Document, Knowledge

from examples.docs.support import MockVectorDB


knowledge = Knowledge(vector_db=MockVectorDB(), context_format="markdown")
knowledge.add(
    Document(content="Definable agents can use knowledge retrieval before responding."),
    chunk=False,
)

agent = Agent(
    model=MockModel(responses=["Knowledge attached."]),
    knowledge=knowledge,
)

output = agent.run("What can agents do?")
context = knowledge.format_context(knowledge.vector_db.search("agents", limit=1))

assert output.content == "Knowledge attached."
assert "knowledge retrieval" in context.lower()
```

With a real model, the retrieved context is injected into the prompt automatically before the answer is generated.
