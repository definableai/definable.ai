`definable.agent.runtime` turns an `Agent` into a long-running service. It has two entry points:

| Type | Purpose |
| --- | --- |
| `AgentServer` | Build a FastAPI app with `/run`, `/health`, webhooks, and mounted interface routes |
| `AgentRuntime` | Supervise the server, interfaces, and time-based triggers in one event loop |

## When to use which

- Use `AgentServer` when you want the ASGI app and control deployment yourself.
- Use `AgentRuntime` when you want the framework to run the server, interfaces, and scheduler together.

## Tested example

```python
from fastapi.testclient import TestClient

from definable.agent import Agent
from definable.agent.runtime import AgentServer
from definable.agent.testing import MockModel

agent = Agent(model=MockModel(responses=["pong"]), instructions="Reply briefly.")
client = TestClient(AgentServer(agent).create_app())

response = client.post("/run", json={"input": "ping", "session_id": "docs-session"})

assert response.status_code == 200
assert response.json()["content"] == "pong"
assert response.json()["session_id"] == "docs-session"
```

## What the runtime mounts automatically

- `POST /run` for direct agent execution
- `GET /health` for health checks
- webhook routes from configured triggers
- router-based interfaces such as call or websocket transports
- observability endpoints when observability is enabled
