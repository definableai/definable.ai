The testing utilities are designed for local, deterministic validation. They are especially useful for documentation, CI, and unit tests where you want to avoid live model calls.

## Tested MockModel basics

```python
from definable.agent import Agent, MockModel


model = MockModel(responses=["Paris"])
agent = Agent(model=model)

output = agent.run("What is the capital of France?")

assert output.content == "Paris"
assert model.call_count == 1
assert len(model.call_history) == 1
model.assert_called_times(1)
```

## Simulating tool calls

`MockModel` is most reliable for tool-call tests when you use `side_effect` and emit OpenAI-style `tool_calls` yourself.

```python
from unittest.mock import MagicMock

from definable.agent import AgentTestCase, MockModel, create_test_agent
from definable.model.metrics import Metrics
from definable.tool.decorator import tool


@tool
def add(a: int, b: int) -> int:
    return a + b


def tool_calling_model(messages=None, **kwargs):
    response = MagicMock()

    if not any(getattr(message, "role", None) == "tool" for message in (messages or [])):
        response.content = ""
        response.tool_calls = [
            {
                "id": "call_1",
                "type": "function",
                "function": {"name": "add", "arguments": '{"a": 2, "b": 3}'},
            }
        ]
    else:
        response.content = "2 + 3 = 5"
        response.tool_calls = []

    response.tool_executions = []
    response.response_usage = Metrics()
    response.reasoning_content = None
    response.citations = None
    response.images = None
    response.videos = None
    response.audios = None
    response.parsed = None
    return response


case = AgentTestCase()
agent = case.create_agent(model=MockModel(side_effect=tool_calling_model), tools=[add])
output = agent.run("What is 2 + 3?")

case.assert_no_errors(output)
case.assert_tool_called(output, "add")
case.assert_content_contains(output, "5")

hello_agent = create_test_agent(responses=["Hello!"])
hello_output = hello_agent.run("Hi")

assert hello_output.content == "Hello!"
```

## Testing the thinking layer

```python
import json

from definable.agent import Agent, MockModel


thinking_json = json.dumps(
    {
        "analysis": "Compare the trade-offs directly.",
        "approach": "Recommend the simpler option first.",
        "tool_plan": None,
    }
)

agent = Agent(
    model=MockModel(
        responses=[
            "fallback",
            "Start with a monolith when speed matters most.",
        ],
        structured_responses=[thinking_json],
    ),
    thinking=True,
)

output = agent.run("Should I start with a monolith or microservices?")

assert output.content.startswith("Start with a monolith")
assert output.reasoning_steps
assert output.reasoning_messages
```

## What to use when

- Use `MockModel(responses=[...])` for simple one-call tests.
- Use `MockModel(side_effect=...)` when you need tool calls, parsed outputs, or other custom response fields.
- Use `AgentTestCase` when you want reusable assertions like `assert_tool_called()` or `assert_no_errors()`.
- Use `create_test_agent()` when you just need a compact one-off helper with tracing disabled.
