Scheduling is built from three pieces:

- A trigger such as `Interval` or `OneShot`.
- A `Scheduler` that fires due jobs.
- A `TriggerExecutor` that turns trigger handler return values into agent runs.

## Tested one-shot scheduler flow

```python
import asyncio

from definable.agent import Agent, MockModel
from definable.agent.scheduler import JobStatus, Scheduler
from definable.agent.trigger import OneShot, TriggerExecutor


async def main() -> None:
    agent = Agent(model=MockModel(responses=["scheduled run"]))
    scheduler = Scheduler(tick_interval=0.01, max_concurrent=1)

    async def handler(event):
        return "Run from schedule"

    trigger = OneShot(delay=0.01)
    trigger.handler = handler
    job = scheduler.add(trigger, name="one-shot-demo", max_runs=1)

    started = []
    completed = []
    scheduler.on_job_started = lambda scheduled_job: started.append(scheduled_job.name)
    scheduler.on_job_completed = lambda scheduled_job: completed.append(
        (scheduled_job.name, scheduled_job.run_count)
    )

    task = asyncio.create_task(scheduler.start(TriggerExecutor(agent)))
    await asyncio.sleep(0.05)
    scheduler.stop()
    await task

    assert job.status == JobStatus.COMPLETED
    assert started == ["one-shot-demo"]
    assert completed == [("one-shot-demo", 1)]
    assert agent.model.call_count == 1


asyncio.run(main())
```

## Trigger basics

```python
from definable.agent import Agent, MockModel
from definable.agent.trigger import Interval, OneShot


interval = Interval(seconds=30)
oneshot = OneShot(delay=1.0)

assert interval.next_run(100.0) == 130.0
assert oneshot.next_run(0.0) == oneshot.fire_at

agent = Agent(model=MockModel(responses=["ok"]))


@agent.on(Interval(seconds=60))
async def every_minute(event):
    return "Run every minute"


scheduler = agent.scheduler

assert scheduler is not None
assert scheduler.job_count == 1
```

## Notes

- Register triggers on an agent with `@agent.on(trigger)`.
- `TriggerExecutor` interprets handler results as `None`, `str`, `dict`, or awaitables and turns strings and dicts into `agent.arun(...)` calls.
- `Cron` is available through `definable.agent.trigger.Cron` when the optional `croniter` dependency is installed.
- `SQLiteJobStore` persists job metadata, but persisted rows do not contain serialized trigger objects. Reattach triggers when restoring jobs.
