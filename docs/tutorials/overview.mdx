Tutorials are the bridge between reference docs and production architecture. Each page in this section focuses on one outcome and uses the same deterministic patterns as the rest of the docs so the examples stay executable.

## What these tutorials optimize for

- assembling several framework layers together,
- choosing the right primitive before you overbuild,
- starting from a local deterministic setup and then swapping in provider-backed components later.

## Tested example

```python
from pathlib import Path

tutorial_pages = sorted(Path("docs/tutorials").glob("*.mdx"))

assert len(tutorial_pages) >= 5
assert any(page.name == "build-a-support-agent.mdx" for page in tutorial_pages)
assert any(page.name == "build-a-rag-assistant.mdx" for page in tutorial_pages)
```
