description: Model a deterministic review pipeline with named steps and step-level outputs.

Use a workflow when you already know the execution graph and want it to be explicit in code. This is the right fit for review, publish, and approval pipelines.

## Shape of the build

1. Define named steps.
2. Pass data between them through `StepInput`.
3. Read the final output from `WorkflowOutput`.
4. Inspect intermediate step output by name when debugging.

## Tested example

```python
import asyncio

from definable.agent.workflow import Step, Workflow


async def research(step_input):
    return "Research notes"


def draft(step_input):
    return f"Draft from {step_input.get_last_step_content()}"


async def main() -> None:
    workflow = Workflow(
        name="review-pipeline",
        steps=[
            Step(name="research", executor=research),
            Step(name="draft", executor=draft),
        ],
    )
    output = await workflow.arun("Write an overview.")

    assert output.success is True
    assert output.content == "Draft from Research notes"
    assert output.get_step_content("research") == "Research notes"


asyncio.run(main())
```

## When to expand this design

- Add `Parallel` when some review branches can run concurrently.
- Add `Condition` or `Loop` when approval depends on explicit criteria.
- Add teams inside steps when one stage still needs model-led collaboration.
