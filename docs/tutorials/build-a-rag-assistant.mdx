This is the simplest end-to-end RAG shape in Definable: build a `Knowledge` instance, load a small corpus, and attach it directly to an `Agent`.

## Shape of the build

1. Create a `Knowledge` object with a vector store.
2. Add documents or files.
3. Attach the knowledge base directly to the agent.
4. Let the agent inject retrieved context before the model call.

## Tested example

```python
from definable.agent import Agent
from definable.agent.testing import MockModel
from definable.knowledge import Document, Knowledge

from examples.docs.support import MockVectorDB

knowledge = Knowledge(vector_db=MockVectorDB(), context_format="markdown")
knowledge.add(Document(content="Escalate billing disputes to finance."), chunk=False)

model = MockModel(responses=["Escalate billing disputes to finance."])
agent = Agent(model=model, knowledge=knowledge)

output = agent.run("What should I do with billing disputes?")
messages = model.call_history[0]["messages"]

assert output.content == "Escalate billing disputes to finance."
assert messages[0].role == "system"
assert "billing disputes" in messages[0].content
```

## When to expand this design

- Add a custom chunker or embedder when the corpus grows.
- Add `KnowledgeToolkit` when retrieval should be optional rather than automatic.
- Add memory only if user/session continuity is also required.
