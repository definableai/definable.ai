description: "Select one or more named routes dynamically."

`Router` chooses which step to execute based on a selector function. The selector can return one route or a list of routes.

## Tested example

```python
import asyncio

from definable.agent.workflow import Router, Step, Workflow


async def main() -> None:
    workflow = Workflow(
        name="support",
        steps=Router(
            name="dispatch",
            selector=lambda step_input: "technical" if "bug" in (step_input.input or "") else "general",
            routes={
                "technical": Step(name="technical", executor=lambda step_input: "Technical queue"),
                "general": Step(name="general", executor=lambda step_input: "General queue"),
            },
        ),
    )
    result = await workflow.arun("There is a bug in checkout.")

    assert result.content == "Technical queue"


asyncio.run(main())
```

## Guidance

- Use routers when the branch set is open-ended or selected dynamically.
- Return multiple route names only when parallel execution is acceptable.
