Sequential execution is the default pattern for workflows expressed as a list of steps.

## Tested example

```python
import asyncio

from definable.agent.workflow import Step, Workflow


async def research(step_input):
    return "Research notes"


def write(step_input):
    return f"Draft from {step_input.get_last_step_content()}"


def edit(step_input):
    return f"Edited: {step_input.get_last_step_content()}"


async def main() -> None:
    workflow = Workflow(
        name="content-pipeline",
        steps=[
            Step(name="research", executor=research),
            Step(name="write", executor=write),
            Step(name="edit", executor=edit),
        ],
    )
    result = await workflow.arun("Write about agents.")

    assert result.content == "Edited: Draft from Research notes"
    assert result.get_step_content("write") == "Draft from Research notes"


asyncio.run(main())
```

## Guidance

- Use sequential steps when each stage depends on the previous one.
- Override `input_builder` on a `Step` when the next prompt needs custom shaping.
