`Workflow` currently exposes `arun()`. The result is a `WorkflowOutput` containing the final content plus per-step results.

## Tested example

```python
import asyncio

from definable.agent.workflow import Step, Workflow


async def research(step_input):
    return "Research notes"


def draft(step_input):
    return f"Draft from {step_input.get_last_step_content()}"


async def main() -> None:
    workflow = Workflow(
        name="publish",
        steps=[
            Step(name="research", executor=research),
            Step(name="draft", executor=draft),
        ],
    )
    result = await workflow.arun("Write an overview.")

    assert result.success is True
    assert result.content == "Draft from Research notes"
    assert result.get_step_output("draft").success is True
    assert result.get_step_content("research") == "Research notes"


asyncio.run(main())
```

## Guidance

- Read `result.content` for the final workflow output.
- Use `get_step_output()` and `get_step_content()` for named step inspection.
- Use `workflow.events` if you need step-level telemetry while the workflow runs.
