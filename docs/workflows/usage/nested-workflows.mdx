title: Nested Workflows
description: Combine parallel, routed, conditional, and looped steps in one orchestrated graph.
---

Nested workflows are useful when one pipeline needs several control-flow primitives instead of a flat sequence.

## Tested example

```python
import runpy

runpy.run_path("examples/docs/workflows_basics.py")
```

## What this covers

- Sequential handoff between named steps.
- Parallel branches.
- Router-based dispatch.
- Looping until a stop condition is met.
- Conditional publish-or-revise branches.
