`MCPToolkit` bridges Model Context Protocol servers into the standard Definable tool system. After initialization, every exposed MCP tool becomes a normal agent tool.

## Tested example

```python
import asyncio
import sys

from definable.mcp import MCPConfig, MCPServerConfig, MCPToolkit

from examples.docs.support import mock_mcp_server_path

config = MCPConfig(
    servers=[
        MCPServerConfig(
            name="mock",
            command=sys.executable,
            args=[str(mock_mcp_server_path())],
        )
    ]
)


async def main() -> None:
    async with MCPToolkit(config) as toolkit:
        tool_names = [tool.name for tool in toolkit.tools]

        assert tool_names == ["mock_echo"]


asyncio.run(main())
```

## Operational notes

- Use the async context manager unless another owner manages the toolkit lifecycle.
- Include the server name in tool names unless you are certain collisions cannot happen.
- Prefer direct `MCPClient` usage when you need resources or prompts more than tools.
