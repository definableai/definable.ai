Use `async def` when the tool waits on external work. The authoring model is the same as for a sync tool; only the entrypoint changes.

## Tested example

```python
import asyncio

from definable.tool import tool
from definable.tool.function import FunctionCall


@tool
async def fetch_record(record_id: str) -> str:
    """Fetch a record asynchronously."""
    await asyncio.sleep(0)
    return f"record:{record_id}"


async def main() -> None:
    result = await FunctionCall(function=fetch_record, arguments={"record_id": "42"}).aexecute()
    assert result.result == "record:42"


asyncio.run(main())
```

## Guidance

- Use async tools for network, database, and file I/O.
- Keep CPU-bound work in sync tools unless you explicitly offload it.
