Create and activate a Python `3.12+` virtual environment before installing dependencies.

- Mac and Linux: run `python3 -m venv .venv`, then `source .venv/bin/activate`.
- Windows: run `python -m venv .venv`, then `.venv\Scripts\activate`.
- `uv`: run `uv venv --python 3.12`, then `source .venv/bin/activate`.
