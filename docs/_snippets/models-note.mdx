<Tip>
You can use string shorthand instead of importing model classes:

```python
from definable.model import OpenAIChat, resolve_model_string

direct = OpenAIChat(id="gpt-4o")
qualified = resolve_model_string("openai/gpt-4o")
defaulted = resolve_model_string("gpt-4o")

assert direct.id == "gpt-4o"
assert qualified.id == "gpt-4o"
assert defaulted.id == "gpt-4o"
assert type(qualified).__name__ == "OpenAIChat"
assert type(defaulted).__name__ == "OpenAIChat"
```

Supported providers: `openai`, `deepseek`, `moonshot`, `xai`, `anthropic`, `mistral`, `google`, `perplexity`, `ollama`, `openrouter`.
</Tip>
