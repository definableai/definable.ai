Mock servers let you validate MCP client, prompt, resource, and toolkit behavior without any external credentials or network dependencies.

## Tested mock server usage

```python
import asyncio
import sys

from examples.docs.support import mock_mcp_server_path
from definable.mcp import MCPClient, MCPConfig, MCPServerConfig


config = MCPConfig(
    servers=[
        MCPServerConfig(
            name="mock",
            command=sys.executable,
            args=[str(mock_mcp_server_path())],
        )
    ]
)


async def main() -> None:
    assert mock_mcp_server_path().name == "mock_mcp_server.py"

    async with MCPClient(config) as client:
        tools = await client.list_tools("mock")
        resources = await client.list_all_resources()
        prompt = await client.get_prompt("mock", "summarize", {"topic": "docs"})

        assert [tool.name for tool in tools] == ["echo"]
        assert resources["mock"][0].uri == "docs://handbook"
        assert prompt.messages[0].content.text == "Summarize docs in three bullets."


asyncio.run(main())
```

## What a good mock server should cover

- At least one tool call path
- At least one resource listing and read path
- At least one prompt listing and rendering path
- One or two failure responses so you can test protocol error handling
