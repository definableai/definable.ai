`MoonshotChat` is the Moonshot-specific OpenAI-compatible adapter. It inherits the OpenAI-style request surface but ships with Moonshot defaults, including the hosted base URL.

## Tested construction

```python
from definable.model import MoonshotChat

model = MoonshotChat(
    id="kimi-k2-turbo-preview",
    api_key="test-key",
    temperature=0.3,
)

assert model.provider == "Moonshot"
assert model.base_url == "https://api.moonshot.ai/v1"
assert model.id == "kimi-k2-turbo-preview"
assert model.temperature == 0.3
```

## Notes

- The adapter follows the OpenAI-compatible parameter model, so request tuning feels similar to `OpenAIChat`.
- Use this class when you want Moonshot-specific defaults instead of configuring `OpenAILike` manually.
