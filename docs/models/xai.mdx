---
title: xAI
description: Configure Grok models through the `xAI` adapter.
icon: magnifying-glass
---

`xAI` wraps Grok models through an OpenAI-compatible transport while still exposing xAI-specific options such as `search_parameters`.

## Tested construction

```python
from definable.model import xAI

model = xAI(
    id="grok-3",
    api_key="test-key",
    temperature=0.5,
    search_parameters={"mode": "auto"},
)

assert model.provider == "xAI"
assert model.base_url == "https://api.x.ai/v1"
assert model.temperature == 0.5
assert model.search_parameters == {"mode": "auto"}
```

## Notes

- Use `search_parameters` when you want Grok's retrieval or search behavior configured at the adapter level.
- The request surface otherwise mirrors the OpenAI-compatible adapters, which makes migrations between providers relatively cheap.
