---
title: Perplexity
description: Configure Perplexity models with the `Perplexity` adapter.
---

`Perplexity` is an OpenAI-compatible adapter, preconfigured for Perplexity's endpoint and model defaults. It is useful when you want Perplexity-specific request settings but the same high-level interface as other OpenAI-protocol providers.

## Tested construction

```python
from definable.model import Perplexity

model = Perplexity(
    id="sonar",
    api_key="test-key",
    max_tokens=256,
    top_k=20,
)

assert model.provider == "Perplexity"
assert model.base_url == "https://api.perplexity.ai/"
assert model.supports_json_schema_outputs is True
assert model.max_tokens == 256
assert model.top_k == 20
```

## Notes

- This adapter reports JSON-schema output support, which matters when you are targeting structured responses through an OpenAI-compatible surface.
- Reach for it when you want Perplexity explicitly represented in configuration and telemetry instead of hiding it behind a generic `OpenAILike` adapter.
