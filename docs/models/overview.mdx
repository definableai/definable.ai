`definable.model` is the provider abstraction layer. It gives the rest of the framework one consistent model interface while still exposing provider-specific classes when you need them.

## Choose the right model surface

| Start with | Use it when |
| --- | --- |
| string shorthand such as `"openai/gpt-4o-mini"` | the model choice should stay configurable |
| provider classes such as `OpenAIChat(...)` or `Claude(...)` | you need provider-specific credentials or options |
| `ResilientModel` or `FailoverChain` | you need retries, failover, or availability across providers |

## Public API

| Type | Purpose |
| --- | --- |
| `OpenAIChat`, `Claude`, `Gemini`, `MistralChat`, `DeepSeekChat`, `MoonshotChat`, `Perplexity`, `OpenRouter`, `Ollama`, `xAI`, `ClaudeCode` | Provider adapters |
| `resolve_model_string` | Parse provider/model shorthand into a model instance |
| `ResilientModel`, `FailoverChain`, `KeyPool` | Reliability and failover helpers |
| `Message`, `ModelResponse`, `Metrics` | Shared model-level types |

## Supported provider families

- OpenAI-compatible providers: OpenAI, OpenRouter, OpenAI-like backends, DeepSeek, Moonshot, xAI, and Perplexity
- frontier providers with dedicated adapters: Anthropic, Google, Mistral, and Ollama
- specialized execution surfaces: Claude Code and resilience wrappers

## Tested example

```python
from definable.model import Claude, OpenAIChat, resolve_model_string

openai = OpenAIChat(id="gpt-4o-mini")
claude = Claude(id="claude-sonnet-4-5-20250929", api_key="test-key")
resolved = resolve_model_string("openai/gpt-4o-mini")

assert openai.id == "gpt-4o-mini"
assert claude.id.startswith("claude")
assert type(resolved).__name__ == "OpenAIChat"
```
