`OpenAILike` is the generic adapter for OpenAI-protocol backends that do not already have a first-class provider wrapper in the library.

## When to use it

- Your upstream endpoint implements the OpenAI chat-completions API.
- You want the OpenAI request surface but a custom `base_url`.
- The provider is internal, proxied, or self-hosted.

## Tested construction

```python
from definable.model import OpenAILike

model = OpenAILike(
    id="custom-model",
    api_key="test-key",
    base_url="https://example.com/v1",
    provider="Internal Gateway",
)

assert model.id == "custom-model"
assert model.provider == "Internal Gateway"
assert str(model.base_url) == "https://example.com/v1"
```

## Typical targets

- Internal gateways and API proxies
- LiteLLM or other routing layers
- Self-hosted OpenAI-protocol servers such as vLLM
- Cloud services that intentionally mirror the OpenAI API
