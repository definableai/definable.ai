`DeepSeekChat` is an OpenAI-compatible adapter preconfigured for DeepSeek's API base URL. It is the right choice when you want DeepSeek-specific defaults without manually setting `base_url` yourself.

## What it exposes

- Public class: `definable.model.DeepSeekChat`
- Provider label: `DeepSeek`
- Default base URL: `https://api.deepseek.com`
- Inherits most request parameters from the OpenAI-compatible adapter surface

## Tested construction

```python
from definable.model import DeepSeekChat

model = DeepSeekChat(
    id="deepseek-chat",
    api_key="test-key",
    temperature=0.4,
    reasoning_effort="medium",
)

assert model.provider == "DeepSeek"
assert model.base_url == "https://api.deepseek.com"
assert model.id == "deepseek-chat"
assert model.temperature == 0.4
assert model.reasoning_effort == "medium"
assert model.supports_native_structured_outputs is False
```

## Use it when

- You want the OpenAI-style request model but with DeepSeek defaults.
- You are switching between OpenAI-compatible providers and want each one represented explicitly.
- You want to keep DeepSeek credentials separate from other OpenAI-protocol backends.
