---
title: Mistral
description: Configure Mistral chat models with `MistralChat`.
---

`MistralChat` exposes Mistral's chat API directly. It advertises native structured-output support and adds provider-specific controls such as `safe_mode`, `safe_prompt`, and `random_seed`.

## Tested construction

```python
from definable.model import MistralChat

model = MistralChat(
    id="mistral-large-latest",
    api_key="test-key",
    temperature=0.2,
    max_tokens=512,
    random_seed=7,
    safe_mode=True,
)

assert model.provider == "Mistral"
assert model.supports_native_structured_outputs is True
assert model.max_tokens == 512
assert model.random_seed == 7
assert model.safe_mode is True
```

## Key options

| Option | Use it for |
| --- | --- |
| `random_seed` | Make sampling reproducible during testing |
| `safe_mode` | Turn on Mistral's safety mode |
| `safe_prompt` | Wrap prompts with Mistral safety guidance |
| `endpoint` | Point the SDK at a custom or proxied endpoint |
