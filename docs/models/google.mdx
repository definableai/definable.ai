`Gemini` is the Google provider adapter. It covers Gemini API settings and Vertex AI settings from the same class, while also exposing Gemini-specific search and grounding controls.

## What this adapter is for

- Use it for Google AI Studio API keys.
- Use it for Vertex AI deployments by setting `vertexai=True`.
- Use it when you need Gemini search, grounding, or thinking budget controls.

## Tested construction

```python
from definable.model import Gemini

model = Gemini(
    id="gemini-2.0-flash-001",
    api_key="test-key",
    search=True,
    grounding=True,
    thinking_budget=512,
    temperature=0.3,
)

assert model.provider == "Google"
assert model.search is True
assert model.grounding is True
assert model.thinking_budget == 512
assert model.temperature == 0.3
```

## Key options

| Option | Use it for |
| --- | --- |
| `vertexai`, `project_id`, `location` | Route calls through Vertex AI instead of AI Studio |
| `search`, `grounding`, `url_context` | Enable Gemini retrieval and grounding features |
| `thinking_budget`, `thinking_level`, `include_thoughts` | Control Gemini-native reasoning features on supported models |
| `response_modalities`, `speech_config` | Configure multimodal generation when the model supports it |

## Notes

- `Gemini` reports native structured-output support.
- If you are standardizing provider choice via config, `google/<model-id>` works with [`resolve_model_string`](/models/model-as-string).
