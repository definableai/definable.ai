Delegation is automatic. In `coordinate` and `route` mode the leader receives an injected `delegate_to_member` tool. In `collaborate` mode the framework delegates to every member directly. In `tasks` mode the leader gets task-management tools as well.

## Tested example

```python
import asyncio

from definable.agent import Agent
from definable.agent.team import MemberDelegatedEvent, Team, TeamMode
from definable.agent.testing import MockModel

from examples.docs.support import mock_model_response


async def main() -> None:
    delegated_members = []
    state = {"calls": 0}

    def leader_side_effect(messages, tools, **kwargs):
        state["calls"] += 1
        if state["calls"] == 1:
            return mock_model_response(
                tool_calls=[
                    {
                        "id": "call-1",
                        "type": "function",
                        "function": {
                            "name": "delegate_to_member",
                            "arguments": '{"member_name": "researcher", "task_input": "research gravity"}',
                        },
                    }
                ]
            )
        return mock_model_response(content="Gravity summary.")

    researcher = Agent(
        model=MockModel(responses=["Gravity attracts masses."]),
        name="researcher",
        instructions="Physics specialist.",
    )
    team = Team(
        name="science-team",
        model=MockModel(side_effect=leader_side_effect),
        members=[researcher],
        mode=TeamMode.coordinate,
    )

    team.events.on(
        MemberDelegatedEvent,
        lambda event: delegated_members.append(event.member_name),
    )
    output = await team.arun("Explain gravity.")

    assert output.content == "Gravity summary."
    assert delegated_members == ["researcher"]


asyncio.run(main())
```

## Guidance

- Keep member instructions crisp so the leader can route clearly.
- Turn on `share_member_interactions=True` only when later delegations should see earlier member output.
- Watch `MemberDelegatedEvent` and `MemberCompletedEvent` if you need auditability.
