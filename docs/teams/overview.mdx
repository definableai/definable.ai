A `Team` is a leader-driven orchestration layer for multiple agents or nested teams. It keeps delegation model-driven while giving you a single entrypoint for multi-specialist work.

## When to use a team

Use a team when:

- one task needs multiple specialist agents
- delegation should stay model-driven instead of hard-coded
- a leader should decide who works next and how to combine outputs

If the process should be explicit and deterministic, prefer a [`Workflow`](/workflows/overview).

## Execution modes

| Mode | What the leader does |
| --- | --- |
| `coordinate` | delegates to selected members and synthesizes the result |
| `route` | chooses one member and returns that member's response |
| `collaborate` | broadcasts the same task to every member and synthesizes |
| `tasks` | manages a shared task list and loops until the goal is complete |

## Tested example

```python
import asyncio

from definable.agent import Agent
from definable.agent.team import Team, TeamMode
from definable.agent.testing import MockModel


async def main() -> None:
    researcher = Agent(
        model=MockModel(responses=["Use qubits and superposition."]),
        name="researcher",
        instructions="Research specialist.",
    )
    writer = Agent(
        model=MockModel(responses=["Explain the idea in plain language."]),
        name="writer",
        instructions="Technical writer.",
    )
    team = Team(
        name="content-team",
        model=MockModel(responses=["Combine the research with a plain-language explanation."]),
        members=[researcher, writer],
        mode=TeamMode.collaborate,
    )

    output = await team.arun("Explain quantum computing.")

    assert output.content == "Combine the research with a plain-language explanation."


asyncio.run(main())
```

## Practical guidance

- Use teams when the orchestration decision should still be model-driven.
- Use workflows when you need explicit step structure and deterministic control flow.
- Start with `collaborate` or `route`; move to `tasks` only when you need autonomous decomposition.
