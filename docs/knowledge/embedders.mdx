Embedders map text into vector space so the knowledge layer can perform semantic search. Provider-specific embedders live behind `definable.embedder`, while the fallback chaining utility is currently exposed from `definable.knowledge`.

## Current import model

- Use `definable.embedder` for provider embedders such as OpenAI, VoyageAI, Google, or Mistral.
- Use `FallbackEmbedder` when you want ordered provider failover.
- Keep the embedder dimensions aligned with the configured vector database.

## Tested example

```python
from examples.docs.knowledge_pipeline import main

summary = main()

assert summary["fallback_dimensions"] == 4
```

## Guidance

- Choose one primary embedder for stable retrieval characteristics.
- Add `FallbackEmbedder` only when transient provider failure is a real operational concern.
- Prefer deterministic dimensions across environments so stored vectors remain compatible.
