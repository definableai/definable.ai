---
title: Hybrid Search
description: Add full-text search to a knowledge base and merge it with vector retrieval.
---

This example keeps the retrieval path deterministic while still exercising the real hybrid search flow: vector results, FTS indexing, merge configuration, and final context formatting.

## Tested example

```python
import asyncio

from examples.docs.support import MockEmbedder, MockVectorDB
from definable.knowledge import Knowledge
from definable.knowledge.fts import FTSIndex, HybridSearchConfig


async def main() -> None:
    fts = FTSIndex()
    await fts.initialize()

    knowledge = Knowledge(
        vector_db=MockVectorDB(embedder=MockEmbedder(dimensions=4)),
        embedder=MockEmbedder(dimensions=4),
        fts_index=fts,
        hybrid_config=HybridSearchConfig(vector_weight=0.7, text_weight=0.3),
    )

    await knowledge.aadd("Python powers the agent runtime.", chunk=False)
    await knowledge.aadd("Memory stores previous interactions.", chunk=False)

    results = await knowledge.asearch("Python runtime", limit=2)
    context = knowledge.format_context(results[:1])

    await fts.close()

    assert results[0].content == "Python powers the agent runtime."
    assert "Python powers the agent runtime." in context


asyncio.run(main())
```
