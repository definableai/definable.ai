---

In the ingestion pipeline, embedders run after chunking and before storage. The preferred provider import path is `definable.embedder`, while `FallbackEmbedder` remains available from `definable.knowledge`.

## Tested example

```python
from examples.docs.knowledge_pipeline import main

summary = main()

assert summary["fallback_dimensions"] == 4
```
