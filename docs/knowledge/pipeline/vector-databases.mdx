Vector databases are the persistence stage of the knowledge pipeline. `Knowledge` writes embedded `Document` chunks into the configured backend and later reads them back through `search()` or `asearch()`.

## Tested example

```python
from examples.docs.knowledge_pipeline import main

summary = main()

assert summary["basic_search_content"] == "Python powers the agent runtime."
assert summary["context_contains_python"] is True
```

## Guidance

- Match vector dimensions to the embedder you chose upstream.
- Keep the database abstraction behind `Knowledge` unless you need direct backend operations.
- Add FTS and hybrid search when vector retrieval alone is not enough.
