title: Pipeline Readers
description: The reader stage that turns files and URLs into knowledge documents.
icon: file-import
---

Readers are the first structured stage in the knowledge pipeline. They normalize sources into `Document` objects so the later chunking and embedding stages can stay source-agnostic.

## Tested example

```python
from examples.docs.knowledge_pipeline import main

summary = main()

assert summary["reader_name"] == "note.txt"
assert summary["reader_content"] == "Plain text content for knowledge ingestion."
```
