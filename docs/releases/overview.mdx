This docs set tracks the package version declared in the repository. Use the package version as the main compatibility anchor for runtime behavior, examples, and deployment decisions.

## What this section is for

- identifying the version series these docs describe,
- understanding how to approach upgrades safely,
- separating current release guidance from migration guidance.

## Tested example

```python
import tomllib
from pathlib import Path

pyproject = tomllib.loads(Path("pyproject.toml").read_text())
version = pyproject["project"]["version"]

assert isinstance(version, str)
assert version.count(".") == 2
```
