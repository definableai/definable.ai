Before you debug provider-specific issues in production, make sure the service surface itself is correct.

## Checklist

- The runtime app answers on `/health`.
- The core execution endpoint works on `/run`.
- Required transport routes are mounted.
- Secrets are injected into the same process that starts the service.
- You have a known-good mock-backed configuration for local rollback testing.

## Tested example

```python
from fastapi.testclient import TestClient

from definable.agent import Agent
from definable.agent.interface import WebSocketInterface
from definable.agent.runtime import AgentServer
from definable.agent.testing import MockModel

agent = Agent(model=MockModel(responses=["pong"]))
interface = WebSocketInterface(path="/agent/ws")
app = AgentServer(agent, interfaces=[interface]).create_app()
client = TestClient(app)
paths = {route.path for route in app.router.routes}

assert client.get("/health").status_code == 200
assert "/run" in paths
assert "/agent/ws" in paths
```

## Rule of thumb

If `/health` or `/run` is broken, stop there. Platform debugging and provider debugging are downstream from runtime shape.
