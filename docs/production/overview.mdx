Production work starts after the local deterministic shape is stable. The order matters:

1. verify the smallest local run,
2. verify the runtime surface,
3. add auth and security,
4. add observability and usage tracking,
5. swap in real providers and infrastructure.

## Tested example

```python
from fastapi.testclient import TestClient

from definable.agent import Agent
from definable.agent.runtime import AgentServer
from definable.agent.testing import MockModel

agent = Agent(model=MockModel(responses=["ok"]), observability=True, usage=True)
client = TestClient(AgentServer(agent).create_app())

assert client.get("/health").status_code == 200
assert client.get("/obs/api/health").status_code == 200
```
