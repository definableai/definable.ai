`Knowledge` orchestrates retrieval: source reading, optional chunking, embedding, vector storage, optional reranking, and prompt-ready context formatting.

## Constructor shape

| Category | Important fields |
| --- | --- |
| Core components | `vector_db`, `embedder`, `reranker`, `chunker`, `readers` |
| Search shaping | `top_k`, `rerank`, `min_score`, `temporal_decay`, `mmr` |
| Hybrid search | `fts_index`, `hybrid_config` |
| Agent integration | `context_format`, `context_position`, `query_from`, `trigger`, `description`, `routing_model` |

## Primary methods

| Method | Purpose |
| --- | --- |
| `add(...)` / `aadd(...)` | ingest file paths, strings, documents, or document lists |
| `search(...)` / `asearch(...)` | retrieve relevant documents |
| `format_context(...)` | turn retrieved documents into prompt-ready text |
| `from_path(...)` | build a ready-to-use local knowledge base from a file or directory |

## Behavior notes

- If no `vector_db` is provided, `Knowledge` defaults to an in-memory vector database.
- If you pass an `embedder`, it takes priority over the vector database's embedder for document insertion.
- `search(...)` accepts both `top_k=` and `limit=` for result-count control.

## Tested example

```python
from definable.knowledge import Document, Knowledge

from examples.docs.support import MockVectorDB

knowledge = Knowledge(vector_db=MockVectorDB(), context_format="markdown")
document_ids = knowledge.add(Document(content="Billing issues go to finance."), chunk=False)
results = knowledge.search("billing", limit=1)
context = knowledge.format_context(results)

assert len(document_ids) == 1
assert results[0].content == "Billing issues go to finance."
assert "Billing issues go to finance." in context
```
