---
title: "@tool"
description: Full reference for the tool decorator and the Function object it returns.
---

`@tool` converts a Python callable into a `Function` object the agent loop can expose to the model. It inspects type hints, infers JSON-schema parameters, captures the docstring as the default description, and attaches runtime flags for confirmation, user input, hooks, and caching.

## Important decorator options

| Option | Purpose |
| --- | --- |
| `name`, `description` | override the inferred tool identity |
| `strict` | enable stricter parameter validation behavior |
| `instructions`, `add_instructions` | attach tool-specific guidance to the agent system prompt |
| `requires_confirmation` | block execution until the user confirms |
| `requires_user_input`, `user_input_fields` | pause execution for additional user-provided values |
| `external_execution` | mark the tool for execution outside the agent process |
| `pre_hook`, `post_hook`, `tool_hooks` | run custom behavior around execution |
| `cache_results`, `cache_dir`, `cache_ttl` | enable result caching |

Only one of `requires_confirmation`, `requires_user_input`, and `external_execution` can be active at the same time.

## Return type

The decorator returns a `Function` object, not a plain Python function. That object still holds the callable entrypoint, but it also carries JSON-schema parameters and runtime metadata used by the agent loop.

## Tested example

```python
from definable.tool import Function
from definable.tool.decorator import tool


@tool(name="lookup_docs", requires_confirmation=True, cache_results=True, cache_ttl=30)
def lookup_docs(topic: str) -> str:
    """Return the docs section for a topic."""
    return f"docs:{topic}"


assert isinstance(lookup_docs, Function)
assert lookup_docs.name == "lookup_docs"
assert lookup_docs.requires_confirmation is True
assert lookup_docs.cache_results is True
assert lookup_docs.cache_ttl == 30
assert lookup_docs.parameters["properties"]["topic"]["type"] == "string"
assert lookup_docs.entrypoint(topic="billing") == "docs:billing"
```
