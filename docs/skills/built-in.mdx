Built-in skills bundle instructions plus tools. They are higher-level than toolkits because they also teach the agent how to use those capabilities.

## Tested built-in surfaces

```python
from definable.skill import (
    Calculator,
    DateTime,
    FileOperations,
    HTTPRequests,
    JSONOperations,
    Shell,
    TextProcessing,
    WebSearch,
)

assert [tool.name for tool in Calculator().tools] == ["calculate"]
assert [tool.name for tool in DateTime().tools] == ["get_current_time", "date_difference"]
assert [tool.name for tool in TextProcessing().tools][:2] == ["regex_search", "regex_replace"]
assert [tool.name for tool in FileOperations(base_dir=".", allow_write=False).tools] == ["read_file", "list_files"]
assert [tool.name for tool in HTTPRequests().tools] == ["http_get", "http_post", "http_put", "http_patch", "http_delete"]
assert [tool.name for tool in JSONOperations().tools] == ["parse_json", "query_json", "transform_json", "compare_json"]
assert [tool.name for tool in Shell(allowed_commands={"ls"}).tools] == ["run_command"]
assert [tool.name for tool in WebSearch(enable_fetch=False).tools] == ["search_web"]
```

## Built-ins covered here

- `Calculator`
- `DateTime`
- `TextProcessing`
- `FileOperations`
- `HTTPRequests`
- `JSONOperations`
- `Shell`
- `WebSearch`

## Notes

- `MacOS` is intentionally documented separately because it depends on the desktop bridge and OS permissions.
- Some built-ins expose optional runtime dependencies only when their tools are actually used, not at import time.
