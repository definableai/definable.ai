The `MacOS` skill exposes desktop automation tools through the local Desktop Bridge. It is appropriate for tightly controlled operator workflows, testing setups, or desktop copilots where the machine boundary is part of the system design.

## Tested example

```python
from definable.skill.builtin.macos import MacOS

skill = MacOS(
    allowed_apps={"Safari", "TextEdit"},
    enable_applescript=False,
)
tool_names = {tool.name for tool in skill.tools}

assert "screenshot" in tool_names
assert "open_app" in tool_names
assert "run_applescript" not in tool_names
```

## Safety guidance

- Keep the bridge on localhost.
- Use `allowed_apps` or `blocked_apps`.
- Disable AppleScript or file-writing tools when they are not required.
