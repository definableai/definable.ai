`SkillRegistry` is the markdown-skill catalog. It loads built-in skills, custom directories, or explicit skill objects and gives you three injection modes: on-demand, eager, and legacy lazy.

## Tested registry workflow

```python
from pathlib import Path
from tempfile import TemporaryDirectory

from definable.skill import SkillLoader, SkillRegistry

with TemporaryDirectory() as tmp:
    skill_path = Path(tmp) / "skill.md"
    skill_path.write_text(
        """---
name: code-review
description: Review code carefully
tags: [code, review]
---
## Steps
Inspect the diff.
""",
        encoding="utf-8",
    )

    skill = SkillLoader.load_file(skill_path)
    registry = SkillRegistry(skills=[skill], include_library=False)

    assert len(registry) == 1
    assert registry.get_skill("code-review").meta.description == "Review code carefully"
    assert [item.meta.name for item in registry.search_skills("review code")] == ["code-review"]
    assert "<available_skills>" in registry.to_prompt()
```

## What changed from older docs

- The recommended registry mode is `as_on_demand()`, not `as_lazy()`.
- `skill_registry=` on `Agent` uses the on-demand catalog/tool pattern.
- Skills can be flat markdown files or directory skills with bundled resources.

## Core surfaces

- `SkillLoader.load_file()` and `SkillLoader.load_directory()` to build markdown skills
- `SkillRegistry.list_skills()`, `get_skill()`, and `search_skills()` for discovery
- `SkillRegistry.as_on_demand()`, `as_eager()`, and `as_lazy()` for injection strategy
