This page is the shortest path from zero to a working agent. It follows the same pattern used by strong framework docs: build the smallest working thing first, then layer on the features that change real behavior.

## What you are building

By the end of this page you will have:

- one runnable agent
- one tool attached to the agent
- one memory store that can preserve prior context
- one streaming loop that exposes run events

## 1. Build the agent

```python
from definable.agent import Agent
from definable.agent.testing import MockModel
from definable.tool import tool


@tool
def get_weather(city: str) -> str:
    """Return a weather summary for a city."""
    return f"{city}: sunny"


agent = Agent(
    model=MockModel(responses=["Tokyo: sunny"]),
    tools=[get_weather],
    instructions="Use tools when they help answer the question.",
)

output = agent.run("What is the weather in Tokyo?")

assert output.content == "Tokyo: sunny"
```

## 2. Add memory

```python
import asyncio

from definable.memory import InMemoryStore, Memory
from definable.model.message import Message


async def main() -> None:
    async with Memory(store=InMemoryStore()) as memory:
        await memory.add(Message(role="user", content="I asked about Paris."), session_id="alice")
        entries = await memory.get_entries("alice")

        assert entries[0].content == "I asked about Paris."


asyncio.run(main())
```

## 3. Stream a response

```python
from definable.agent import Agent
from definable.agent.testing import MockModel

agent = Agent(model=MockModel(responses=["hello world"]), instructions="Be brief.")
events = [event.event for event in agent.run_stream("Say hello") if hasattr(event, "event")]

assert "RunContent" in events
assert "RunCompleted" in events
```

## What to swap for production

- Replace `MockModel(...)` with a real model from [`definable.model`](/models/overview).
- Replace `InMemoryStore()` with a persistent store if you want memory across process restarts.
- Attach [`Knowledge`](/knowledge/overview), [`Guardrails`](/guardrails/overview), or [`Interfaces`](/interfaces/overview) as needed.
