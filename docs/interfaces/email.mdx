`EmailInterface` polls an inbox, converts inbound messages into the interface pipeline, and sends agent responses back through SMTP. It is designed for asynchronous support queues, triage agents, and systems where a long-lived thread matters more than low-latency chat.

## Tested example

```python
from definable.agent.interface import EmailInterface

email = EmailInterface(
    imap_host="imap.example.com",
    smtp_host="smtp.example.com",
    email_address="agent@example.com",
    email_password="secret",
    subject_prefix="[Agent] ",
    reply_quote_original=False,
)

assert email.config.platform == "email"
assert email._email_config.email_address == "agent@example.com"
assert email._email_config.subject_prefix == "[Agent] "
assert email._email_config.reply_quote_original is False
```

## What it handles

- IMAP polling for new inbound mail.
- SMTP replies with threading headers preserved.
- Session scoping by sender and thread metadata.
- Optional quoting of the original message in outbound replies.

## Operational notes

- `imap_host`, `smtp_host`, `email_address`, and `email_password` are the core connection settings.
- Email defaults are tuned for lower throughput than chat interfaces, including a smaller concurrent request budget.
- Because IMAP and SMTP are blocking protocols, the interface manages that complexity internally. The agent-facing surface stays async.
