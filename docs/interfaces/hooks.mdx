Interface hooks are the cross-cutting layer for transports. They let you intercept inbound messages, rewrite them before the agent runs, post-process responses, or record failures without modifying the platform interface itself.

## Hook phases

- `on_message_received(message)` can veto a message by returning `False`.
- `on_before_respond(message, session)` can replace the inbound message.
- `on_after_respond(message, response, session)` can replace the outbound response.
- `on_error(error, message)` observes failures during processing.

## Tested example

```python
import asyncio
from dataclasses import replace

from definable.agent.interface import InterfaceMessage, InterfaceResponse, InterfaceSession


class PrefixHook:
    async def on_message_received(self, message: InterfaceMessage) -> bool | None:
        if message.platform_user_id == "blocked":
            return False
        return None

    async def on_before_respond(
        self,
        message: InterfaceMessage,
        session: InterfaceSession,
    ) -> InterfaceMessage | None:
        return replace(message, text=f"[reviewed] {message.text}")

    async def on_after_respond(
        self,
        message: InterfaceMessage,
        response: InterfaceResponse,
        session: InterfaceSession,
    ) -> InterfaceResponse | None:
        return InterfaceResponse(content=f"{response.content} | sent")


hook = PrefixHook()
message = InterfaceMessage(
    platform="telegram",
    platform_user_id="u-1",
    platform_chat_id="chat-1",
    platform_message_id="m-1",
    text="hello",
)
session = InterfaceSession(platform="telegram", platform_user_id="u-1", platform_chat_id="chat-1")

assert asyncio.run(hook.on_message_received(message)) is None
updated = asyncio.run(hook.on_before_respond(message, session))
assert updated is not None
assert updated.text == "[reviewed] hello"

response = asyncio.run(hook.on_after_respond(message, InterfaceResponse(content="done"), session))
assert response is not None
assert response.content == "done | sent"

blocked = replace(message, platform_user_id="blocked")
assert asyncio.run(hook.on_message_received(blocked)) is False
```

## Built-in hooks

- `AllowlistHook` drops messages from users outside a configured set.
- `LoggingHook` records inbound messages and interface errors.

## Usage guidance

- Put transport-wide policy here before adding agent-specific middleware.
- Use hooks for access control, audit markers, and message normalization.
- Keep hooks deterministic and fast. They run on every message.
