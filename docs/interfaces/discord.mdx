`DiscordInterface` wraps `discord.py` and normalizes Discord messages into the standard interface pipeline. It is a good fit when you want a bot that can operate in servers, direct messages, and threaded conversations with the same agent logic you use elsewhere.

## Tested example

```python
from definable.agent import Agent
from definable.agent.interface import DiscordInterface
from definable.agent.testing import MockModel

agent = Agent(
    model=MockModel(responses=["ready"]),
    interfaces=[
        DiscordInterface(
            bot_token="discord-token",
            command_prefix="!",
            allowed_guild_ids=[1234],
        )
    ],
)

discord = agent.interfaces[0]

assert discord.agent is agent
assert discord.config.platform == "discord"
assert discord._dc_config.command_prefix == "!"
assert discord._dc_config.allowed_guild_ids == [1234]
```

## What it supports

- Guild channels and direct messages.
- Message prefix filtering through `command_prefix`.
- Channel and guild allowlists through `allowed_channel_ids` and `allowed_guild_ids`.
- Attachment normalization for images, audio, and files.
- Per-thread or per-channel session isolation through the standard session layer.

## Setup notes

- Enable the `MESSAGE_CONTENT` privileged intent for bots that need full message text.
- Install the Discord extras before deploying the interface.
- Bind the interface through `Agent(interfaces=[...])` and let the runtime supervise it.
