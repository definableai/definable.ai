This is the tested configuration shape for Telegram. Replace the mock model with your production model, decide between polling and webhooks, and run the agent through the runtime once the bot token is in place.

## Tested example

```python
from definable.agent import Agent
from definable.agent.interface import TelegramInterface
from definable.agent.testing import MockModel

agent = Agent(
    model=MockModel(responses=["ready"]),
    interfaces=[
        TelegramInterface(
            bot_token="123:test",
            commands={"start": "Start the bot"},
            group_mode="mention",
        )
    ],
)

telegram = agent.interfaces[0]

assert telegram.agent is agent
assert telegram.config.commands == {"start": "Start the bot"}
assert telegram.config.group_mode == "mention"
```

## Deployment checklist

- Use polling for local development and webhooks for public deployments.
- Configure DM and group policies before exposing the bot broadly.
- Replace the mock model with your production model.
