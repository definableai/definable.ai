This is the current deployment shape for Slack. Replace the mock model with your production model, choose Socket Mode or HTTP mode, and let the runtime supervise the interface once your app credentials are configured.

## Tested example

```python
from definable.agent import Agent
from definable.agent.interface import SlackInterface
from definable.agent.testing import MockModel


async def handle_ask(command: dict) -> None:
    return None


slack = SlackInterface(
    bot_token="xoxb-test",
    app_token="xapp-test",
    slash_commands={"/ask": "Ask the assistant"},
    done_reaction="white_check_mark",
)
slack.on_command("/ask", handle_ask)

agent = Agent(
    model=MockModel(responses=["ready"]),
    interfaces=[slack],
)

configured = agent.interfaces[0]

assert configured.agent is agent
assert configured._slack_config.done_reaction == "white_check_mark"
assert "/ask" in configured._command_callbacks
```

## Deployment checklist

- Use Socket Mode for private development environments.
- Switch to `mode="http"` with a signing secret for public deployments.
- Install the Slack extras before running the interface.
