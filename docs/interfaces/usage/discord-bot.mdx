This page shows the deployment shape, not a live provider session. Replace the mock model with your production model, install the Discord extras, and run the agent through the runtime once your bot token and intents are configured.

## Tested example

```python
from definable.agent import Agent
from definable.agent.interface import DiscordInterface
from definable.agent.testing import MockModel
from definable.tool.decorator import tool


@tool
def lookup_docs(topic: str) -> str:
    return f"docs:{topic}"


agent = Agent(
    model=MockModel(responses=["ready"]),
    tools=[lookup_docs],
    interfaces=[
        DiscordInterface(
            bot_token="discord-token",
            command_prefix="!",
            allowed_guild_ids=[1234],
        )
    ],
)

discord = agent.interfaces[0]

assert discord.agent is agent
assert discord._dc_config.command_prefix == "!"
assert discord._dc_config.allowed_guild_ids == [1234]
assert len(agent.tools) == 1
```

## Deployment checklist

- Enable the `MESSAGE_CONTENT` intent for bots that need full text.
- Install the Discord extras before running the interface.
- Replace `MockModel(...)` with your production model.
