When a transport appears dead, verify the runtime surface before you debug platform credentials or message formatting.

## Fast checks

- Confirm the runtime app responds on `/health`.
- Confirm the expected route or WebSocket path is mounted.
- Confirm the interface type actually requires a server, rather than a background polling loop.

## Tested example

```python
from fastapi.testclient import TestClient

from definable.agent import Agent
from definable.agent.interface import WebSocketInterface
from definable.agent.runtime import AgentServer
from definable.agent.testing import MockModel

agent = Agent(model=MockModel(responses=["pong"]), instructions="Reply briefly.")
interface = WebSocketInterface(path="/ws", heartbeat_interval=5.0)
app = AgentServer(agent, interfaces=[interface]).create_app()
client = TestClient(app)
paths = {route.path for route in app.router.routes}

assert interface.needs_server() is True
assert client.get("/health").json()["status"] == "ok"
assert "/run" in paths
assert "/ws" in paths
```

## If it still fails

- Missing route: confirm the interface is attached to the runtime or passed into `AgentServer`.
- Health check fails: fix the server process first; platform debugging is downstream from that.
- WebSocket works locally but not in deployment: inspect proxy and load balancer WebSocket support before touching agent code.
