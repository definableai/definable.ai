`definable.agent.observability` exposes a lightweight runtime view into active runs. It is designed for local debugging, staging inspection, and operational visibility without forcing you into a third-party tracing stack.

## Public API

| Type | Purpose |
| --- | --- |
| `ObservabilityConfig` | Runtime settings for the dashboard and API |
| `ObservabilityExporter` | Collector used to buffer and expose events |

## What you get

- `/obs/` dashboard for local inspection
- `/obs/api/*` endpoints for health and event data
- access to run and phase metrics produced by the pipeline

## Tested example

```python
from fastapi.testclient import TestClient

from definable.agent import Agent
from definable.agent.runtime import AgentServer
from definable.agent.testing import MockModel

agent = Agent(model=MockModel(responses=["ok"]), observability=True)
client = TestClient(AgentServer(agent).create_app())

health = client.get("/obs/api/health")
dashboard = client.get("/obs/")

assert health.status_code == 200
assert dashboard.status_code == 200
```

## Guidance

- Treat observability as a runtime aid, not as your long-term storage layer.
- Keep it enabled in development and staging.
- Pair it with replay or exported traces when you need historical comparison.
